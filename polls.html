Research Notes & Methodology

PRP calculation: The map uses every poll record supplied for a state. The displayed average is a simple, unweighted average of the reported poll margins (and of the aligned Trump and Harris percentages). No date window is applied. It is a PRP calculation, not an official RealClearPolitics average or an election forecast.

Data coverage: This page only includes records present in the text file supplied for this project. A gray state does not mean that the state had no polling; it means no records for that state were present in this dataset.

Candidate columns: The copied text did not retain candidate column headers. Candidate percentages are aligned using each poll's reported spread (for example, “Trump+2” or “Harris+3”); the two original values are preserved in the JSON as raw_first and raw_second.

Source: RealClearPolitics poll records supplied by the project owner. Original pollster, field dates, sample size, voter screen, margin of error, raw values, and reported spread are retained in the data file.

Polling is a snapshot of opinion, not a prediction of the final result. Small samples of available polls should be interpreted cautiously. Averaging all polls (including earlier ones) is useful for historical comparison but is not a late-campaign forecast.
